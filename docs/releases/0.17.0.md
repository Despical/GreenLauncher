Green Launcher 0.17.0

Updates
- Added automatic update checks at launch and every six hours, plus manual checks in Settings > About.
- New releases appear on the home page with their changelog and a subtle notification in the bottom bar.
- Added download progress, cancellation, retry and an explicit restart-and-update action.
- Downloads are verified before installation. Interrupted or failed downloads leave the current launcher intact; completed downloads are cached for later retries.
- Only newer stable versions can be installed. Games and active launcher operations must finish before installation.
- A Windows setup is now available for one-time installation and subsequent in-app updates. Existing profiles, accounts, worlds and server lists are preserved.

Worlds and servers
- World table dividers now appear only between values, not between column headings.
- Added icons to the four world details in the right panel.
- Hover and selection backgrounds now extend across the full width of both tables.
- Includes per-profile server synchronization with Minecraft and world management, including exact seeds in both legacy and Minecraft 26.1+ saves.
