Green Launcher 0.17.1

- Restored the missing 0.17.0 update manifest and installer blockmap, allowing existing installations to check for updates again.
- Missing release files now produce a distinct message instead of a connection error.
- Moved the update panel from About to a separate box at the bottom of Settings > Launcher.
- Fixed the rounded bottom corners of the final row in world and server tables during hover and selection.
- Aligned world and server icons with the name column headings.
- Added a green Latest badge beside the newest version title in the left changelog menu.

Update assets: the setup EXE, installer blockmap and latest.yml are required for in-app updates and must remain attached to the release.
